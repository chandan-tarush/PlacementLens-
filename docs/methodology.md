# Methodology

PlacementLens calculates metrics from the currently selected dataset version. It uses distinct student IDs for placed students when IDs are available, otherwise placement rows. Placement rate is calculated only as placed students / eligible students where an eligible denominator exists. Salary distribution and summary values use individual CTC-labelled salaries. Potential IQR outliers are flagged and retained. Comparisons show unavailable rather than manufactured values when fields are incompatible.
